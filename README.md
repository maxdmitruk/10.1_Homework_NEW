Transaction Utils

Набор вспомогательных функций для фильтрации и сортировки списка транзакций (словарей).

Цель проекта

Предоставить простые и надежные инструменты для обработки данных о финансовых операциях. Функции позволяют отфильтровать список по статусу (state) и отсортировать его по дате (date), используя аннотации типов для удобства разработки и статического анализа кода.

Установка

Проект не требует сторонних зависимостей, кроме стандартной библиотеки Python 3.6+.

Скопируйте файл с функциями (например, utils.py) в ваш проект или создайте виртуальное окружение:
bash
Копировать
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
Сохраните код функций в файл transaction_utils.py.
Использование

Импортируйте необходимые функции из модуля:

python
Копировать
from transaction_utils import filter_by_state, sort_by_date
Фильтрация по состоянию: filter_by_state

Функция возвращает новый список словарей, содержащих только те элементы, у которых значение ключа state совпадает с указанным.

Сигнатура функции:

python
Копировать
def filter_by_state(data_list: list[dict[str, any]], state: str = 'EXECUTED') -> list[dict[str, any]]:
    ...
data_list: Исходный список словарей.
state: Искомое состояние. По умолчанию — 'EXECUTED'.

Примеры работы:

python
Копировать
transactions = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]

# Получаем только выполненные операции (по умолчанию)
executed = filter_by_state(transactions)
print(executed)
# [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
#  {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# Получаем отмененные операции
canceled = filter_by_state(transactions, 'CANCELED')
print(canceled)
# [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
#  {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
Сортировка по дате: sort_by_date

Функция возвращает новый список, отсортированный по значению ключа date. Формат даты должен быть совместим с ISO 8601 (например, YYYY-MM-DDTHH:MM:SS.ssssss). Строки этого формата сортируются лексикографически так же, как и хронологически.

Сигнатура функции:

python
Копировать
def sort_by_date(data_list: list[dict[str, any]], descending: bool = True) -> list[dict[str, any]]:
    ...
data_list: Исходный список словарей.
descending: Порядок сортировки. True (по умолчанию) — от новых к старым (убывание), False — от старых к новым (возрастание).

Примеры работы:

python
Копировать
# Входные данные намеренно перемешаны
unsorted_transactions = [
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]

# Сортировка по убыванию (сначала самые новые)
newest_first = sort_by_date(unsorted_transactions)
print(newest_first)
# [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
#  {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
#  {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
#  {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# Сортировка по возрастанию (сначала самые старые)
oldest_first = sort_by_date(unsorted_transactions, descending=False)
print(oldest_first)
# [{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
#  {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
#  {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
#  {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}]
Комбинирование функций

Функции можно легко объединять благодаря тому, что каждая из них возвращает новый список, не изменяя исходный:

python
Копировать
# Сначала фильтруем, затем сортируем результат
recent_canceled = sort_by_date(
    filter_by_state(transactions, 'CANCELED')
)
Тестирование

Для проверки корректности работы функций вы можете использовать предоставленные примеры входных данных. Рекомендуется покрыть функции базовыми unit-тестами, проверяющими:

Корректность фильтрации при наличии и отсутствии целевого состояния.
Порядок сортировки для обоих режимов (descending=True/False).
Поведение функций на пустом списке.
Отсутствие ошибок при обработке элементов без ключей state или date (если используется безопасная версия sort_by_date_safe).

Пример простого теста через стандартный модуль doctest или unittest поможет убедиться, что изменения в коде не сломают ожидаемую логику.
